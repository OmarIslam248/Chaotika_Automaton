# Test Plan and Results

All checklists below were passed by the final prototype.

## Visual
- [x] Cams, shafts and copper wire properly installed
- [x] Glue secure and not interfering with moving parts
- [x] Moving figures positioned correctly
- [x] Base stable and well balanced

## Motion
- [x] Handle turns smoothly, no sticking or wobble
- [x] Dog barks in a consistent up/down motion
- [x] Two small birds move up and down consistently
- [x] Predator bird moves up and down consistently
- [x] No moving parts collide

## Durability (100 consecutive crank turns)
- [x] All moving parts still rotate correctly
- [x] No cams or shaft loosened or shifted
- [x] No wires bent or disconnected
- [x] Handle remains attached

## Child safety
- [x] No sharp edges or pinch points
- [x] Wire ends looped, not exposed
- [x] Handle sized for small hands
- [x] Hot glue fully dry
- [x] Lightweight and safe to handle

## Motion timing
- [x] Sequence follows dog, birds, fire
- [x] Cams timed correctly relative to each other
- [x] Visual testing aids working
- [x] Parts return to start position smoothly

## Child survey (scored 1–10)

| Metric | Score |
|---|---|
| Engagement (interest/fun) | 9 |
| Understanding of scene | 8 |
| Ease of handle use | 9 |
| Safety/comfort | 8 |
| Durability over play | 7 |

Test aids built into the design: colour-coded cams, accessible base for inspection, modular removable components.
